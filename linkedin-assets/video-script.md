# 45-Second Demo Video — Shot-by-Shot Script

**Setup before recording:**
- Backend + worker running (live or local with real WhatsApp number connected)
- Dashboard open in browser (logged in as manager), technician APK open on your phone
- Second phone (or WhatsApp Web in another window) acting as the "customer"
- Screen recorder: OBS (free) for desktop + phone screen-record; or record phone with the desktop visible behind it in one continuous shot
- Use a test customer name — no real customer data on screen

| # | Time | Shot | On-screen text overlay |
|---|---|---|---|
| 1 | 0–5s | Customer phone: type "hi, RO se paani slow aa raha hai" in WhatsApp, send | "Customer sends ONE WhatsApp message 📱" |
| 2 | 5–12s | Bot replies asking name/address; fast-forward the short Q&A; ticket confirmation "OG-XXXX" appears | "AI bot captures the request → ticket created" |
| 3 | 12–18s | Cut to dashboard: the new ticket appears on the board WITHOUT refreshing | "Appears live on the manager dashboard 🖥️" |
| 4 | 18–24s | Manager clicks Assign → picks technician → sets slot | "One-click assignment" |
| 5 | 24–30s | Technician phone: job pops into Today's Jobs; tap Accept | "Job lands on the technician's phone 🔧" |
| 6 | 30–38s | Quick montage on tech app: I'm On The Way → Mark Arrived (GPS) → TDS entry → estimate screen | "GPS proof · TDS readings · estimate" |
| 7 | 38–43s | Customer phone: estimate message arrives, reply approves; tech app shows VERIFIED ✅ | "Customer approves BEFORE any paid work" |
| 8 | 43–45s | End card (use visual-4-cover.png) | "1 system · 3 surfaces · 0 lost inquiries" |

**Recording tips:**
- Vertical 9:16 or square 1:1 crops best on LinkedIn mobile feed
- Add captions/overlays (CapCut is easiest) — 80% of LinkedIn videos play muted
- No voiceover needed; overlays + a light music track are enough
- Keep it under 60s; LinkedIn autoplays and short videos get replayed (replays boost reach)
- Blur/rename anything real: customer names, phone numbers, the WhatsApp number if you want
